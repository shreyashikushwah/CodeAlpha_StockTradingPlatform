# CodeAlpha_StockTradingPlatform
Java console app simulating a stock trading platform — buy/sell stocks, track portfolio value and profit/loss. Built for the CodeAlpha Java Programming Internship.

## Description
This program simulates a basic stock trading environment. Users start with virtual cash, 
can view live-simulated market prices, buy and sell stocks, and track their portfolio's 
performance over time — all built using Object-Oriented Programming principles.

## Features
- Simulated market with fluctuating stock prices (randomized each round)
- Buy and sell stocks with balance/ownership checks
- Portfolio tracking: cash balance, current holdings, and total value
- Profit/loss calculation compared to starting investment
- Transaction history log

## Technologies Used
- Java
- Object-Oriented Programming (OOP): Stock, User, Market, and Transaction classes
- Java Collections (ArrayList, HashMap)
